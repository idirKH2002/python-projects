# Parking Management System

## Overview
This project is a parking management system developed in Python during my academic studies.

The application uses object-oriented programming principles to simulate the management of a parking service, including vehicles, subscriptions, parking spots, contracts, and deliveries.

---

## Features
- Vehicle management
- Parking spot allocation
- Subscription handling
- Access management
- Delivery and service management
- Client and contract management

---

## Technologies
- Python
- Object-Oriented Programming (OOP)

---

## Project Structure
The project is organized into multiple classes to ensure modularity and maintainability.

It also includes:
- Unit test files
- Main execution file
- Project documentation (PDF)

---

## Objective
The objective of this project was to improve programming logic, software organization, and object-oriented development skills through a real-world management system simulation.
